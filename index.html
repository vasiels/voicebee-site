Installation

macOS may show "VoiceBee is damaged and can't be opened" because the app is not yet code-signed. To fix this:

Option 1: Run this command in Terminal:

xattr -cr /Applications/VoiceBee.app

Option 2: Use System Settings:

  1. Try to open VoiceBee (it will fail)
  2. Go to System Settings → Privacy & Security
  3. Scroll down and click "Open Anyway"

Windows may show a SmartScreen warning because the app is not yet code-signed. To install:

  1. Run the installer (.exe file)
  2. If you see "Windows protected your PC", click "More info"
  3. Click "Run anyway"

Requirements

  • macOS 10.15+ (Apple Silicon) or Windows 10/11 (64-bit)
  • Microphone permission
  • Accessibility permission (macOS only, for typing at cursor)
