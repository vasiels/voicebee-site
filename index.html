Installation Guide

VoiceBee is not yet code-signed. Here's how to install it.

macOS may show "VoiceBee is damaged and can't be opened" because the app is not yet code-signed.

Option 1: Terminal command (recommended)

Open Terminal and run:

xattr -cr /Applications/VoiceBee.app
or

Option 2: System Settings

  1. Try to open VoiceBee (it will fail)
  2. Go to System Settings → Privacy & Security
  3. Scroll down and click "Open Anyway"
Accessibility permission: VoiceBee needs Accessibility access to type text at your cursor. The app will prompt you on first launch. If text goes to your clipboard instead of being typed, re-enable the permission in System Settings → Privacy & Security → Accessibility.

Windows may show a SmartScreen warning because the app is not yet code-signed.

Installation steps

  1. Run the downloaded .exe installer
  2. If you see "Windows protected your PC", click "More info"
  3. Click "Run anyway"
  4. Follow the installation wizard
MSI installer: An MSI installer is also available from the releases page if your organization requires it.

Frequently Asked Questions

Everything you need to know about VoiceBee.

Yes, VoiceBee is completely free and open source. You need a free account to use cloud transcription (powered by OpenAI Whisper), but there are no charges or premium tiers.
VoiceBee is not yet code-signed with an Apple Developer certificate. macOS quarantines unsigned apps as a security measure. Running xattr -cr /Applications/VoiceBee.app in Terminal removes the quarantine flag. See the installation guide for details.
Audio is sent to OpenAI's Whisper API for transcription and immediately discarded. It is not stored on disk, in the cloud, or anywhere else. Your transcription history (text only) is saved locally on your machine.
Yes! Go to Settings inside the app and set any key combination you like. The default is Alt+Space, but you can use Ctrl, Shift, or Cmd modifiers, or even single F-keys (F1–F24).
Currently, VoiceBee requires an internet connection for cloud-based transcription. Offline support via local Whisper is planned for a future release.
On macOS: Microphone (to record audio) and Accessibility (to type text at your cursor). On Windows: only microphone access is needed. VoiceBee will prompt for these on first launch.
VoiceBee checks for updates automatically in the background. When a new version is available, you'll see a notification in the app. Click to download and install — the app will restart with the latest version. On macOS, you may need to re-grant Accessibility permission after an update since the binary changes.
