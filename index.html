Quick Setup

Ready in 30 seconds

VoiceBee is an independent app. Your OS may ask for permission the first time — here's how to approve it instantly.

Since VoiceBee is distributed independently (not through the App Store), macOS Gatekeeper may require a one-time approval.

Option 1 — One terminal command:

xattr -cr /Applications/VoiceBee.app

Option 2 — System Settings:

  1. Open VoiceBee (macOS will show a security prompt)
  2. Go to System Settings → Privacy & Security
  3. Click "Open Anyway" — done!

Windows SmartScreen may show a one-time warning for apps downloaded outside the Microsoft Store.

  1. Run the installer (.exe file)
  2. Click "More info" on the SmartScreen prompt
  3. Click "Run anyway" — you're all set!

System Requirements

  • ✓ macOS 10.15+ (Apple Silicon & Intel) or Windows 10/11 (64-bit)
  • ✓ Microphone permission
  • ✓ Accessibility permission (macOS only, for typing at cursor)
